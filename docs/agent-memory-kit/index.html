Wayline Memory Kit

One shared memory for every person and coding agent who works on Wayline. HANDOFF.md says where the last session stopped, and ROADMAP.md says where the product is going. Two scripts keep both honest.

  1. Start

    Read HANDOFF.md section 1, skim sections 4 and 6, run roadmap.py next, compare git status.

  2. Work

    Mark the sub-goal doing, record new work in ROADMAP.md at once, and ask the owner about every decision.

  3. Finish

    Check tasks with dated proof, run roadmap.py write, log the session, then pass check_handoff.py --strict.

How Wayline runs the kit

The kit below is stored unchanged in docs/agent-memory-kit/, including its templates. Wayline adapts it in these places:

tests/agent-memory.test.mjs
Replaces the kit's two pytest files, because Wayline tests with node --test. It runs both validators inside npm test and skips them when Python is missing.
.github/workflows/ci.yml
Runs roadmap.py check and check_handoff.py --strict after the build. The kit's separate agent-memory.yml is not installed: it would duplicate these steps, and pushing a new workflow file needs a token with the workflow scope.
.agent-memory.json
Counts server/, src/, scripts/, tests/ and configuration as code. docs/, standalone/ and output/ never force a handoff entry on their own.
Horizons
Short-term is Launch 1, the hosted Boston pilot without booking. Mid-term is Launch 2, contracted booking and payments. Long-term is growth beyond Boston.
Python on Windows
On the owner's laptop python3 opens the Microsoft Store, so run python. CI on Ubuntu uses python3.
